# Embedded Study

C 기초 문법을 아는 입문자를 위한 개인 학습 웹입니다.

## 스터디원이 실행하는 방법

초대를 수락한 GitHub 계정으로 비공개 저장소를 내려받습니다. Python 3.10 이상이 필요하며 추가 패키지 설치는 없습니다.

```sh
git clone https://github.com/wooca12/embedded-study.git
cd embedded-study
python3 server.py
```

브라우저에서 http://127.0.0.1:8000 을 열어주세요. 각자의 컴퓨터에서 실행하며, 이 주소 자체를 다른 사람에게 보내는 방식은 아닙니다. 업데이트할 때는 저장소에서 `git pull`을 실행합니다.

강의 PDF와 그림도 함께 내려받아집니다. 웹 하단의 원본 링크 또는 [Day 1 강의 PDF](web/private/day1/day1-firmware.pdf)로 확인할 수 있어요. 실제 AI 답변은 각자 서버에 API 키를 설정해야 하며, 설정 전에도 개념 학습·복습·질문 기록은 사용할 수 있습니다.

## Day 01

NUCLEO-F103RB / STM32F103RB. 제공된 PDF의 7개 장을 따라 개요 → 개발환경 → 클럭·핀·프로젝트 설정 → LED → 버튼 → UART → 표준 입출력 → 도전 과제로 학습합니다. 포인터·MMIO·레지스터는 별도 보충 학습입니다. [강의 대응표](docs/lecture-map.md)를 확인하세요.

- `web/`: 강의 예습 10단계 + 보충 2단계와 기초 질문, 비트 연습, 보드 실습, 복습 12문항, 랜덤 발표·타이머, 글 작성·내보내기
- [MMIO 보충 코드 안내](studies/01-mmio-gpio/README.md)
- [Mac 설치 안내](docs/mac-setup.md)
- [기술 출처](docs/sources.md)

진도·이해도·메모·블로그 초안·외부 링크·개념별 대화·추가 개념 정리는 localStorage에 저장됩니다. 같은 브라우저와 주소(포트 포함)에서만 유지되며 서버 동기화는 없습니다. JSON 백업·복원 기능을 사용하세요. 링크 입력은 기록용이며 GitHub나 Velog에 자동 게시하지 않습니다.

## 질문 도우미

개념별 질문 → 답변을 다듬어 해당 개념에 저장 → 블로그 초안에 추가 → Markdown으로 보관할 수 있습니다. 실제 AI 답변은 서버의 OpenAI API 키 설정이 필요합니다. 키 없이도 질문 기록과 받은 답변 직접 추가는 사용할 수 있어요. [설정·사용 안내](docs/chat-setup.md)를 참고하세요.

## 기록 흐름

예습 → 보드 실습 → 관찰 기록 → 복습·발표 → 직접 블로그 작성 → Markdown 내려받기 → 이 저장소에 저장 → Velog에 발행 → 양쪽 링크 추가.

## 공유 범위

이 저장소는 6명 스터디용 비공개 저장소입니다. 사용자 요청에 따라 강의 PDF 원본과 그림 12개를 `web/private/day1/`에 함께 보관합니다. 강의 자료의 공개 재배포나 Velog 게시용으로 사용하지 않습니다. 설명과 실습 예제는 학습을 위해 새로 작성했으며, 실제 보드 동작은 미검증입니다.

API 키가 들어가는 `.env`, 브라우저 학습 기록 백업, 임시 파일은 Git에서 제외합니다. 진도·질문·개인 정리는 각자의 브라우저에 저장되며 멤버 사이에 자동 동기화되지 않습니다.

저장소 관리자는 Settings → Collaborators에서 스터디원의 GitHub 아이디를 초대하면 됩니다. GitHub 저장소 공유이며, 별도의 웹 호스팅은 하지 않습니다.
