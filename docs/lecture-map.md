# 오늘의 스터디: Memory-mapped I/O와 GPIO 제어

강의 목차를 재현하는 대신 오늘의 질문인 ‘코드가 어떻게 핀의 전압을 바꾸는가?’를 중심으로 내용을 재구성했습니다.

| 순서 | 배우는 내용 | 설명할 수 있어야 하는 것 |
|---|---|---|
| 1 | 코드에서 LED까지 | Mac·ST-LINK·MCU·GPIO의 역할 |
| 2 | C 주소·포인터·비트 | 주소 접근과 마스크 연산 |
| 3 | MMIO | RAM 접근과 주변장치 레지스터 접근의 차이 |
| 4 | GPIO 기본 | 입출력·풀업·풀다운·출력 방식 |
| 5 | GPIO 준비 | 클럭 허용·CRL/CRH·PA5 출력 설정 |
| 6 | GPIO 출력 | ODR·BSRR·HAL의 연결 |
| 7 | GPIO 입력 | IDR·PC13·active-low·폴링·바운스 |
| 8 | 전체 연결 | 버튼 입력 → 판단 → LED 출력의 흐름 |

실습은 비트 연습 → HAL LED → BSRR 출력 → 버튼 입력 순서입니다. UART·printf/scanf·센서 통신·다른 제조사 보드·전체 강의 제출 과제는 이번 학습 범위에서 제외합니다. 보드 초기 설정에 필요한 설치 안내는 별도 참고로 유지합니다.

## 사용한 자료

- 기존 Firmware Day 1 PDF: 보드·GPIO·LED·버튼을 이해하는 데 필요한 내용과 그림만 참고합니다. 화면에서는 p.27, 44, 76, 84, 102, 108 그림 6개를 사용합니다. 저장소에 이미 있던 원본과 다른 그림은 참고 자료로 유지합니다.
- 추가 제공된 Embedded_Firmware_Study_Day1-5.pdf(22쪽): p.2의 Core·MCU·보드 구분, p.4의 GPIO·풀업·입력 상태와 이벤트, p.9의 출력 방식, p.18의 바운스·상태 변화 구분을 참고했습니다. 이 파일의 원본을 저장소에 새로 업로드하지는 않았습니다.
- ST RM0008·UM1724·STM32F1 HAL: MMIO·GPIO 레지스터와 보드 연결을 설명하기 위한 공식 자료입니다. MMIO는 추가 통합 노트에서 직접 설명하는 주제가 아니므로 별도 보완했습니다.

## 기존 개인 기록

학습 구조 버전 3은 이전 버전의 대화·개인 정리를 관련 개념으로 옮깁니다. 오늘 범위 밖인 UART·표준 입출력·종합 도전 과제의 정리는 ‘블로그 정리 → 이전 주제의 개인 정리’에서 유지하고 전체 JSON 백업에도 포함합니다. 블로그 초안·실습 메모·링크는 덮어쓰지 않습니다. 예습 진도·복습 평가는 새 내용에 맞춰 다시 시작합니다.

실제 보드에서의 빌드·동작은 미검증입니다.
