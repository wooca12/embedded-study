## 보충 학습

- 보충 1: C 포인터·주소·비트 마스크
- 보충 2: MMIO·volatile·GPIO 레지스터, 클럭·CRL·BSRR 코드

위 두 항목은 강의의 별도 장을 옮긴 것이 아닙니다. 사용자 주제인 MMIO를 이해하도록 추가한 설명입니다. 강의 본문 중 Mac 적용·기술적 정정·바운스 등도 ‘보충’으로 표시합니다.

## 강의 그림

p.27, 36, 44, 51, 76, 84, 102, 108, 122, 125, 137, 144의 그림 12개를 관련 단계에 배치했습니다. 읽는 방법을 함께 표시하고 확대해서 볼 수 있습니다. 사용자 요청에 따라 원본 PDF와 그림을 `web/private/day1/`에 보관하고 스터디 저장소에 포함합니다. 정적 학습 사이트에 함께 제공하며, 블로그 내보내기에는 포함하지 않습니다.

## 실습과 검증 범위

강의 목표에 맞춰 새로 작성한 학습 예제가 포함되어 있습니다. 링크된 강의 원본 코드와 동일한 구현이라는 의미는 아닙니다. 실제 보드 빌드·실행은 미검증입니다. 실습 화면은 강의의 LED → 버튼 → UART → 표준 입출력 → 도전 과제 순서이며 직접 레지스터 제어는 보충 실습으로 분리했습니다.

## 기존 기록

기존 6개 개념의 대화·추가 정리는 새 관련 항목으로 옮깁니다. 포인터는 보충 1, MMIO·레지스터는 보충 2, GPIO는 버튼 단계, HAL은 LED 단계로 연결합니다. 실습 메모·블로그 초안·외부 링크는 유지합니다. 내용이 달라진 예습 진도와 복습 평가는 초기화합니다. 이전 버전 JSON 복원에도 같은 변환을 적용합니다.
