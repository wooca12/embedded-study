# 개념 질문과 학습 기록

## 실행

기존 정적 서버 대신 저장소 루트에서 다음 명령을 사용합니다. Python 표준 라이브러리만 필요합니다.

```sh
python3 server.py
```

http://127.0.0.1:8000 에 접속합니다. 서버는 이 컴퓨터에서만 접근 가능한 127.0.0.1에 바인딩합니다.

## 실제 AI 연결

1. `.env.example`을 `.env`로 복사합니다.
2. `.env`의 OPENAI_API_KEY에 자신의 OpenAI API 키를 입력합니다. 채팅 메시지나 브라우저에 키를 붙여 넣지 않습니다.
3. 필요하면 OPENAI_MODEL을 변경합니다. 기본값은 gpt-4.1-mini입니다.
4. 서버를 재시작하고 질문창의 ‘연결 다시 확인’을 누릅니다.

환경 변수로 설정한 값이 .env보다 우선합니다. .env는 Git에서 제외되며 정적 웹 루트(web/) 밖에 있습니다. API 이용에는 계정의 요금·한도가 적용됩니다.

API 키가 없어도 질문 기록을 저장하고 다른 곳에서 받은 답변을 직접 추가할 수 있습니다. 실제 AI 답변은 연결 설정 후에 가능합니다.

## 사용 흐름

1. 예습 카드의 ‘이 개념 질문하기’를 누릅니다.
2. 질문합니다. 주제별 대화가 저장되며 최근 완료된 10회 대화가 다음 질문에 전달됩니다.
3. 답변 아래 ‘개념 정리에 저장’을 누릅니다.
4. 질문과 핵심 정리를 직접 다듬어 저장합니다. 원본 대화는 유지됩니다.
5. 해당 개념 아래 ‘질문하며 배운 내용’에 표시됩니다.
6. 필요하면 정리를 수정·삭제하거나 블로그 초안에 추가합니다.

블로그는 자동 발행하지 않습니다. 동일한 정리 내용을 중복 추가하지 않으며 수정된 정리를 추가하면 새 내용이 덧붙습니다. 기존 블로그 글의 표현을 자동 덮어쓰지 않습니다.

## 저장과 백업

대화와 추가 정리는 기존 진도·블로그와 동일한 localStorage 키에 저장되고 ‘전체 학습 기록 백업’ JSON에 함께 포함됩니다. 이전 버전 백업도 읽을 수 있으며 새 필드가 없으면 빈 대화·정리로 가져옵니다. 복원은 현재 기록을 대체합니다. 필요한 기록은 복원 전 백업하세요.

‘추가 개념 정리 내려받기’로 개인 정리를 Markdown으로 저장할 수 있습니다. PDF 그림은 Markdown이나 JSON에 포함하지 않습니다.

## 전송 범위

API 요청 시 선택한 개념의 자체 작성 설명, 질문, 같은 개념의 최근 대화만 OpenAI로 보냅니다. PDF 원본·슬라이드 그림·다른 개념의 대화·블로그·API 키는 브라우저 요청에 포함하지 않습니다. Responses API에 store:false를 사용합니다. 이것이 모든 서비스 로그의 무보존을 뜻하지는 않습니다.

답변은 모델의 설명이며 실제 보드 테스트나 실시간 문서 검색 결과가 아닙니다. 핵심 내용은 공식 문서와 비교해 확인할 수 있습니다.
